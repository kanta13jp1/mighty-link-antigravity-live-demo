# Grill Me

Use this Skill when implementation would benefit from sharper requirements.

## Method

1. Restate the goal and confirmed constraints in one short paragraph.
2. Ask only questions whose answers materially change the result.
3. Ask one question at a time and wait for the answer.
4. Include one recommended answer and a one-line reason with each question.
5. Respect any question limit in the user's prompt.
6. Do not edit files, run commands, or contact external services during the interview.
7. Finish with four headings: Decisions, Out of scope, Stop conditions, Success criteria.

Do not continue into implementation until the user accepts the summary or explicitly asks to proceed.
